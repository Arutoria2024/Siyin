祀音 1.1.0

双击桌面快捷方式启动。首次加载模型需要约 1～2 分钟。关闭窗口收进托盘；退出请使用托盘菜单。
需要 Windows 10/11 x64、WebView2 Runtime、支持 Vulkan 的显卡，建议为安装与临时文件预留至少 6GB 空间。建议显存 6GB，首次启动时关闭其他重负载程序。C 盘空间不足时在安装页面选择其他磁盘。
请勿与另一套本地语音服务同时运行（9880、9881、9882、9888 端口）。
合成、TXT 批量、作品库、多格式导出、音量及 API/MCP 均可在工作台使用。
文本语言可选中文、英文、中英混合。新合成的作品自动进行呼吸音抑制与 EQ 后处理，播放和导出方式不变。首次英文使用包含前端预热，需稍等。
API 地址 http://127.0.0.1:9881；每次新安装自动生成独立密钥，保存在 app/services/config.json。MCP 配置可在接入页复制。
局域网访问默认关闭，在“接入与设置 → 网络访问”点击开关启用。页面自动识别本机 IP，局域网入口默认 9890，可保存为其他空闲端口。其他设备可用浏览器打开该地址，输入 API Key 登录工作台；语音 API 使用同一地址并携带 Bearer Key。网络设置和复制 Key 仅在服务电脑上操作。
首次放行 Windows 防火墙可能弹出管理员授权提示；规则仅允许本地子网访问当前端口。关闭局域网开关停止入口，本机访问继续可用，防火墙规则保留供下次使用。IP 或安装目录变化后请刷新地址、重新配置规则。公网隧道与 HTTPS 不在本轮自动部署范围内。
作品保存在 app/out/workbench；升级前请备份该目录及 app/services/config.json。安装升级不覆盖已有配置；卸载不会主动删除作品。
安装器由多卷文件组成时，请把 Setup.exe 和全部 .bin 文件放在同一文件夹。
本包不含开发机密钥、历史作品、日志、测试文件或 node_modules。
