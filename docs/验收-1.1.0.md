# 祀音 1.1.0 验证记录

日期：2026-11-06。设备：RTX 2060 6GB，Windows，si / v5turbo，语速 0.88，4 步。引擎来源与校验和见 runtime-lock.json。

## 本轮实际完成

- 自动测试 34 项通过：包括新增的英文语言/分词边界、空流报错、处理参数校验、关闭后 PCM 不变、FFmpeg 缺失保留原声、中文路径及 24/48kHz 真实滤镜处理。
- 前端 TypeScript + Vite 正式构建通过，桌面启动器重新编译为 1.1.0.0。安装包使用同一套已构建的界面、Python 源码、成套 EXE/DLL 与修复后的英文依赖。
- 新旧引擎使用同一份模型与参考音频逐个启动，没有并行加载两套 GPU 模型。旧文件已独立备份。
- 真实中文、英文、中英混合推理，英文和混合输出由原来的静音变为有效音频。采样中的直流均值为 0.000005～0.000011，正负波形均存在，未发现上游提示的明显半波/直流异常。
- 工作台任务验证中文原声 24kHz、英文处理版 24kHz、混合处理版 48kHz；原声与交付母版均可读取。关闭后处理的两个 WAV 逐字节一致。新任务保存语言及处理配置，历史记录迁移默认不处理。
- 未传任何后处理参数的普通工作台提交，自动完成处理，样例记录后处理耗时 378 ms；界面不需要额外操作。
- 以上作品的 WAV/MP3/FLAC/M4A/Ogg/PCM 导出可读取；ffprobe 核对了编码格式、采样率与单声道。Opus 容器按编码器规范显示 48kHz，不把它描述为提升原始音质。
- 真实波形与播放器沿用原版，播放和导出统一使用成品。页面仅增加文本语言选择，后处理自动完成。此次没有重做全套 1920×1080 / 150% 缩放视觉验收。
- `/v1/tts` 处理开/关均返回有效 WAV 和正确 X-Postprocess；流接口非法语言或 postprocess=true 返回 400。
- 七项 MCP 实际调用通过；另用 stdio 进程完成 initialize、tools/list（七项）和英文 tts_speak，确认原声备份与处理结果存在。MCP 回归后的业务配置与测试前一致。

## 性能实测

同一句约 6.7 秒的中文，分别独立启动旧/新引擎，排除每轮首次请求后各取三次热态中位数；未开启新增注意力近似优化。测试数目小，仅代表本机此语料。

| 指标 | 旧版 | v0.1.2 | 变化 |
|---|---:|---:|---:|
| 首个 PCM 到达 | 1851 ms | 1807 ms | -2.38% |
| 生成总耗时 | 1869 ms | 1826 ms | -2.30% |
| RTF | 0.2789 | 0.2725 | -2.30% |

中文 PCM 长度同为 160800 个样本，新旧最大差异 1 个 16bit 量化单位，平均绝对差异约 0.00844，相关系数约 0.9999999997。不是逐字节完全相同。

首次候选请求含文本前端/引擎预热，中文约 6.9 秒、首次英文约 6.8 秒；不把冷启动数值混入热态表。实时试听仍走原声。三段约 6～7 秒的音频，后处理分别约 487/271/243 ms，限制 CPU 两个线程。成品完成时间会增加这部分实际耗时。

## 尚未验证与保留事项

- 本轮没有再次运行超 2000 字真实长文、完整公网链路、全部温控场景、磁盘不足、长时间压力/内存增长及全新机器安装卸载；相关历史验收不算本轮通过。
- FFmpeg 动态响度处理的目标值不等于每份成品的实测值，不宣称消除所有呼吸声或保持所有辅音不变。可关闭或按音色调整预设，原声始终保留。
- 未替换 si 模型、参考音频和历史作品，未推送或提交 Siyin 仓库。

完整原始测量暂存于本机升级验证目录；合成样例在工作台“升级验收”作品中。源码仓库不收录私人配置、模型或测试音频。
