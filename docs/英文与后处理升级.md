# 英文与语音后处理升级

## 本轮改动

跟进 [KakaruHayate/gsv.cpp v0.1.2](https://github.com/KakaruHayate/gsv.cpp/releases/tag/v0.1.2)，保留 si 权重、参考音频、默认语速 0.88、4 步和既有功能。前端增加正文语言选择：中文、英文、中英混合。

新合成作品默认自动进行呼吸音抑制与 EQ 后处理。作品库、播放器与导出统一使用完成后的成品，操作方式沿用原版。

## 引擎与运行环境

上游提交、下载地址及成套文件 SHA-256 见 [runtime-lock.json](runtime-lock.json)。EXE 与四个 ggml DLL 必须一起替换，同时升级 text_sidecar.py 和 frontend/frontend.py，保留 MSVC 运行库。

中文 G2PW 仍依赖 ONNX Runtime。英文使用 g2p_en、inflect、wordsegment 与 NLTK 数据。本次修复了 typeguard 4.6.0 与旧 typing_extensions 文件冲突，采用已校验的 typing_extensions 4.15.0。

text_lang=en 仅改变正文语言，auto 用于中英混合；中文参考文本的 prompt_lang 保持 zh。注意力窗口与 CFG 跳过暂设为 0，保持升级前的行为。模型跨语言读音仍受音色本身能力影响。

## 自动后处理

实现位于 app/services/postprocess.py。处理顺序：

agate → afftdn → 高通/EQ → deesser → 压缩 → loudnorm → limiter

采用提供规范的呼吸抑制与 EQ 参数。24kHz deesser 为 0.35，48kHz 为 0.4；limiter 显式使用 level=false，避免自动补偿增益影响限幅。保留既有分段停顿。

工作台逐段接收、处理并保存成品，最后合并为 master.wav。原始分段仅作内部恢复资料，处理失败后重试可复用，历史作品不自动改写。FFmpeg 限制 CPU 两个线程，跨进程串行执行；不启动新的模型实例。

实时试听沿用原有低延迟音频流，自动后处理在成品阶段完成。缺少 FFmpeg 或处理失败会明确报错，保留已生成的分段。

## 维护与接口

私有配置 postprocess 默认启用 breath_guard 和 eq；支持 voices.si 的 threshold、ratio、attack、release、range、nr、nf 预设，数值有上下界校验。界面自动使用默认预设。工作台新任务读取当前配置；修改常驻网关配置后需重启。

保留已有 HTTP 路径、PCM 契约及七个 MCP 名称。新增可选 text_lang；完整 WAV 与 MCP 合成默认自动后处理，详细参数和返回见 [API](接入规范/API.md)及[MCP](接入规范/MCP.md)。技术接入仍可显式 postprocess=false 获取原始输出，普通使用不需要设置。

新版安装包排除文本源码目录中的重复 G2PW 模型/下载包，正式模型从 app/models/frontend/g2pw 加载。模型、私人配置与用户作品不放入源码仓库。

实际测试和本机性能见 [1.1.0 验证记录](验收-1.1.0.md)。
