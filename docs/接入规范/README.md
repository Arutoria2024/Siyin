# 祀音开发接入规范

适用版本：祀音 1.0.0。核对日期：2026-11-06。以本项目当前实现为准。

- [API.md](API.md)：HTTP 网关、鉴权、流式与完整 WAV、客户端示例、局域网与公网跳接。
- [MCP.md](MCP.md)：stdio 配置、七个工具的参数/返回、JSON-RPC 示例。
- [mcp-tools.json](mcp-tools.json)：从实际运行的 tools/list 导出的七项工具定义。

第三方应用通常连接 HTTP 网关；本机 Agent 可通过 MCP 管理参数或合成到文件。工作台内部管理接口不作为远程应用公共协议。

## 本机核对结果

| 项目 | 当前状态 |
|---|---|
| 本机网关 | http://127.0.0.1:9881 |
| 当前局域网入口 | http://<LAN_IP>:9890（IP 自动识别，端口可配置） |
| 网关监听 | 127.0.0.1:9881；可选局域网入口 0.0.0.0:9890 |
| API Key | 已配置，本文不保存真实值 |
| 未带 Key / 错误 Key 的合成请求 | HTTP 401 |
| 正确 Key + 空 JSON | HTTP 400，表明鉴权通过并进入文本参数校验 |
| MCP | 实际 stdio initialize、tools/list 和只读 tts_status 调用通过 |
| 工作台/模型/文本服务 | 9888 / 9880 / 9882 仅监听 127.0.0.1 |

局域网入口新增工作台登录和 API 转发，开关在“接入与设置 → 网络访问”。已在服务电脑上通过局域网 IP 验证登录、任务读取和真实 WAV 合成；防火墙已确认允许所选端口且 RemoteAddress 为 LocalSubnet。未从另一台设备完成连通性验证。公网域名、HTTPS 和服务器隧道尚未部署。本轮未重复运行修改参数、切换模型等有副作用的 MCP 工具；此前版本已有完整功能回归记录。

## 集成默认值

音色 si；语速 0.88；步数 4；默认 24000 Hz、单声道、16 位有符号小端 PCM。不要为了接入而修改模型参数。

目录路径均相对于项目根目录。示例中的 <PROJECT_ROOT> 是本机路径，安装到其他目录后按实际路径替换。旧 app/docs 和 docs_for_codex 中的 F: 路径及供应商设想不应替代本目录的当前实现规范。

## 密钥

本地配置在 app/services/config.json 的 gateway.token。不要将真实配置或密钥提交到公开仓库。外部应用通过自己的配置/环境变量持有 Key，本文所有示例均用占位符。
